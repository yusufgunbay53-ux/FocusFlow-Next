# FocusFlow

AI Destekli Görev ve Odaklanma Asistanı

Modern, karanlık mod odaklı, neon mavi ve derin gece mavisi tonlarında minimalist bir web uygulaması.

## Özellikler

- **Akıllı Görev Yönetimi**: Öncelik etiketli (Düşük/Orta/Yüksek) Todo, sürükle-bırak Kanban (Yapılacaklar / Yapılıyor / Tamamlandı)
- **Gelişmiş Pomodoro**: 25 dk çalışma / 5 dk mola, tarayıcı bildirimi + sesli uyarı
- **Lo-Fi / Yağmur Sesi**: Arka planda çalınabilir ses oynatıcı (ses kontrolü ile)
- **AI Performans Koçu**: Görev ve Pomodoro verilerine göre akıllı geri bildirimler (mock, API'ye hazır)
- **localStorage**: Veriler sayfa yenilense de korunur
- **Glassmorphism**, hover efektleri, mobil uyumlu (PWA hazır)

## Teknolojiler

- Next.js 14 (App Router)
- React 18
- Tailwind CSS
- Lucide React (ikonlar)
- @dnd-kit (drag & drop)
- Framer Motion (animasyonlar)

## Kurulum

```bash
npm install
npm run dev
```

Tarayıcıda http://localhost:3000 açın.

## Gelecek Geliştirmeler

Veri yapıları Supabase / Firebase entegrasyonuna hazır şekilde modülerdir.
